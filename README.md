## SQL E-COMMERCE ANALYSIS SCRIPT 
OverviewThe script performs the following operations on an ecommerce database:
1. Creates and uses the ecommerce database.
2. Displays all tables.
3. Queries data from a sales_data table with various analytical tasks:
    - Fetches all records from sales_data.
    - Retrieves customers from the "West" region.
    - Displays the top 5 highest sales amounts.
    - Calculates total sales per region.
    - Counts total customers per region.
    - Computes the average sales amount.
